# Numerical Solution of Differential Equations

在微分方程数值解课程学习过程中各种数值方法实现代码、结果图表和复习整理笔记。

This repository stores my numerical-methods code, result plots, and organized review notes for a Numerical Solution of Differential Equations course.

## 内容概览 / Contents

- `assignments/`：四次大作业的 MATLAB 代码、输出图表和结果表格。
- [复习讲义网页版](https://witchlilian.github.io/numerical-solution-of-DE-public/)：GitHub Pages 直接渲染版本。

## 主要知识点 / Topics

- 有限差分公式、局部截断误差、一致性、稳定性和收敛性。
- 一维边值问题、ghost point、Neumann 边界条件处理。
- 二维 Poisson 方程、natural row ordering、矩阵组装、Jacobi、Gauss-Seidel 和 SOR。
- 抛物型方程：forward Euler、backward Euler、Crank-Nicolson、method of lines 和 ADI。
- 双曲型方程：upwind、Lax-Friedrichs、Lax-Wendroff、CFL 条件和数值边界条件。
