1. 通用判题模板

题型标准写法最容易丢分处
Consistency 把 exact solution u 代入差分算子 P_h，算 T = P_h u - P u。若 T -> 0，则 consistent；若 T = O(hp + kq)，就是 p 阶空间、q 阶时间。 不要把数值解 U 代进去；local truncation error 用 exact u。
Stability 时间格式：Fourier mode e^{iθj} 得增长因子 G(θ)，要求 sup_θ |G| <= 1。迭代格式：误差迭代 er+1=B er，要求 ρ(B)<1。 FTCS 对 advection 是不稳定；FTCS 对 heat 只有 μ ≤ 1/2 稳定。
Convergence 误差 = 稳定放大常数 × 截断误差。线性初边值问题可写 consistent + stable => convergent。 不能只说 consistent 就 convergent；还要 stable。
Matrix A 先定 unknown ordering，再写 interior stencil，最后改边界行/RHS。自然排序常用 L = i + (m-1)(j-1)。 Neumann 不只是 RHS 变，ghost point 会把相邻系数从 1 改成 2。

2. 第2章：1D Boundary Value Problems

核心公式

u′(xi) ≈ ui+1 - uih = O(h) u′(xi) ≈ ui - ui-1h = O(h) u′(xi) ≈ ui+1 - ui-12h = O(h2) u″(xi) ≈ ui-1 - 2ui + ui+1h2 = O(h2)

三对角 BVP：对 u'' = f，Dirichlet 边界 u(a)=α, u(b)=β：

A = 1h2 tridiag(1, -2, 1) F1 = f1 - αh2 Fn-1 = fn-1 - βh2

若是 u'' - K u = f，则主对角变为 -2/h2 - K。

非均匀网格三点公式

点为 x-h1, x, x+h2，H=h1+h2。

u′(x) ≈ -h2h1Hu(x-h1) + h2-h1h1h2u(x) + h1h2Hu(x+h2) 误差主项 = (h1h2/6)u‴(x)，当 h1,h2 同量级时为 O(h2)。
u″(x) ≈ 2h1Hu(x-h1) - 2h1h2u(x) + 2h2Hu(x+h2) 误差主项 = ((h2-h1)/3)u‴(x)+O(h2)。一般非均匀是一阶；h1=h2 时退化为二阶。

三点不能一致逼近 u'''：要同时消掉 u、u'、u'' 并保留 u'''，至少需要 4 个独立条件，三点系数不够。

Ghost point 方法

若右端 Neumann：u'(b)=g，unknown 包含 U_n≈u(b)。中心差分边界：

Un+1-Un-12h = g  ⇒  Un+1 = Un-1 + 2hg

代入最后一个二阶方程：

Un-1-2Un+Un+1h2 = fn ⇒ 2Un-1-2Unh2 = fn - 2gh 最后一行：A(n,n-1)=2/h2，A(n,n)=-2/h2，F(n)=fn-2g/h。

周期边界矩阵

对 u''(x)-q(x)u=f，u(a)=u(b)，令 unknown 为 U_1,...,U_n，且 U_0=U_n, U_{n+1}=U_1。矩阵是 cyclic tridiagonal，不是普通三对角：

Ai,i = -2h2 - qi Ai,i-1 = Ai,i+1 = 1h2 周期边界额外角元素：A1,n=1/h2，An,1=1/h2。
Newton 非线性 BVP 代码思路

对 F(U)=0：先用差分写每个 residual R_i，再写 Jacobian J_ij = ∂R_i/∂U_j，迭代解 J delta = -R，更新 U = U + delta，直到 max(abs(delta)) 或相邻迭代差小于 tol。

while err > tol
  build R(U)
  build jacobian J(U)
  delta = -J \ R;
  Unew = U + delta;
  err = max(abs(Unew-U));
  U = Unew;
end

最大值原理与误差

4. 第4章：Parabolic PDEs

1D heat equation：ut = βuxx + f

格式scheme精度稳定性
Forward Euler Uin+1=Uin+μ(Ui-1n-2Uin+Ui+1n)+kfin O(k+h2) β>0 时 μ=βk/h2 ≤ 1/2
Backward Euler -μUi-1n+1+(1+2μ)Uin+1-μUi+1n+1=Uin+kfin+1 O(k+h2) 无条件稳定
Crank-Nicolson (I-kL/2)Un+1=(I+kL/2)Un+k(fn+1+fn)/2 O(k2+h2) 线性 heat 无条件稳定
MOL 空间先离散成 dU/dt = A U + F(t)，再用 ode15s/ode23s 看空间和 ODE solver 热方程半离散通常 stiff

Assignment 3 Q1 模板

给定 scheme：

Uik+1 = αUik + 1-α2(Ui+1k+Ui-1k) α = 1 - 2βμ，μ = Δth2

代入 α 后：

Uik+1 = Uik + βΔtUi-1k-2Uik+Ui+1kh2

这就是 Forward Euler + central second derivative，所以 consistent，local truncation error O(Δt+h2)。

CN 稳定性证明一句话版

令离散 Laplacian 的特征值 λ ≤ 0。 CN 增长因子：R(λ)=1+βkλ/21-βkλ/2 因为 λ≤0，所以 |R(λ)|≤1，对任意 k,h 成立 ⇒ unconditionally stable。

若多了中心差分 advection：L = βδ_xx + aδ_x，Fourier 符号 λ(θ)= -4βsin2(θ/2)/h2 + iasinθ/h，实部仍 <=0，CN 的 |(1+kλ/2)/(1-kλ/2)|<=1，仍稳定。

2D CN 与 ADI

2D CN: Un+1-Unk = 12(ΔhUn+1+ΔhUn) + 12(fn+1+fn) 精度 O(k2+h2)；线性问题无条件稳定，但矩阵是 block tridiagonal。
ADI 两步： Un+1/2-Unk/2 = δxxUn+1/2 + δyyUn + fn+1/2 Un+1-Un+1/2k/2 = δxxUn+1/2 + δyyUn+1 + fn+1/2

ADI 的考试关键词：每半步只解一批三对角系统；比 2D CN 直接解大矩阵便宜；线性 heat 无条件稳定；作业 exact solution e^{-t} sin x cos y 对应 f=e^{-t} sin x cos y，因为 ut=-u 且 uxx+uyy=-2u。

5. 第5章：Hyperbolic PDEs

一阶 advection：ut + aux = 0

特征线：x - a t = const。若 a>0，信息从左向右，左边界是 inflow，需要给 u(0,t)；右边界是 outflow，通常不应强加物理边界，但某些中心型格式需要 numerical boundary condition。

格式更新式，ν=ak/h精度稳定性
FTCS Ujn+1=Ujn-(ν/2)(Uj+1n-Uj-1n) O(k+h2) 无条件不稳定
Upwind, a>0 Ujn+1=Ujn-ν(Ujn-Uj-1n) O(k+h) 0 ≤ ν ≤ 1
Lax-Friedrichs Ujn+1=0.5(Uj+1n+Uj-1n)-(ν/2)(Uj+1n-Uj-1n) O(k+h) when k~h |ν| ≤ 1
Lax-Wendroff Ujn+1=Ujn-(ν/2)(Uj+1n-Uj-1n) + (ν^2/2)(U_{j+1}^n-2U_j^n+U_{j-1}^n) O(k2+h2) |ν| ≤ 1

Numerical Boundary Condition

一阶外推 UMn+1 = UM-1n+1 二阶外推 UMn+1 = 2UM-1n+1 - UM-2n+1 准特征一阶 UMn+1 = UM-1n

考试判断：主格式稳定不够，NBC 也可能破坏整体稳定性；upwind 在 outflow 端通常不需要额外 NBC。

二阶 wave equation

utt = a2uxx 可写为一阶系统，特征速度 ±a；解的依赖域是 [x-at, x+at]。显式中心格式稳定条件通常也是 CFL：ak/h ≤ 1。

7. 证明题答题骨架

证明某 scheme consistent
  1. 定义 local truncation error：T = exact solution 代入差分格式后左边减右边。
  2. 把所有 u(x±h,t±k) 在 (x_i,t_n) Taylor 展开。
  3. 用 PDE 消去主项，例如 heat 中 ut=βuxx，advection 中 ut=-aux。
  4. 写 T=O(k^p+h^q)。若 p,q 正，则 consistent。
证明 Forward Euler heat 稳定
令 Ujn=Gneiθj G = 1 + μ(e-iθ-2+eiθ) = 1 - 4μsin2(θ/2) 要求 |G|≤1 对所有 θ：-1 ≤ 1 - 4μsin2(θ/2) ≤ 1 ⇒ 0 ≤ μ ≤ 1/2
证明 CN heat 无条件稳定
CN: (I-kβD/2)Un+1 = (I+kβD/2)Un D 的特征值 λ≤0；每个 mode 的放大因子 G=1+kβλ/21-kβλ/2 λ≤0 ⇒ 分子绝对值不超过分母 ⇒ |G|≤1，所以对任意 k,h 稳定。
判 Lax-Friedrichs 稳定
G = cosθ - iνsinθ |G|2 = cos2θ + ν2sin2θ = 1-(1-ν2)sin2θ 要求 |G|≤1 ⇒ |ν|≤1
写 Poisson 矩阵 A
  1. 画格点，标出 unknown 是否包含 Neumann 边界。
  2. 写 ordering，例如 L=i+(m-1)(j-1)。
  3. 对每个 unknown 写 left+right+down+up-4center=h2f。
  4. Dirichlet：已知值移到 RHS；Neumann：先用 ghost relation 消 ghost，再写系数。
  5. 最后检查每行主对角通常是 -4/h2，Neumann 行相邻系数可能是 2/h2。

8. 考前速背清单

必须背到能默写

  • 三点中心：u' 二阶，u'' 二阶。
  • local truncation error：exact u 代入，不是 numerical U。
  • 1D Dirichlet BVP 三对角矩阵和 RHS 边界修正。
  • Neumann ghost：相邻系数翻倍，RHS 出现 ±2g/h。
  • Poisson 五点矩阵：自然排序、block tridiagonal。
  • Jacobi/GS/SOR 更新式，SOR 中 0<ω<2。
  • Forward Euler heat：μ<=1/2。
  • Backward Euler / CN / ADI：线性 heat 无条件稳定。
  • Upwind/LF/LW：CFL |a|k/h<=1。
  • FTCS advection：不稳定。

常见陷阱

  • “consistent” 不等于 “convergent”；还缺 stable。
  • 中心差分处理强 convection 可能振荡；upwind 更稳但一阶。
  • 2D 数组和自然排序别混：MATLAB 里 meshgrid 后 U(row,column)=U(y,x)。
  • CN 的 RHS 也有旧时刻 Laplacian，不只是 U^n。
  • ADI 每半步的边界时间不同，t+dt/2 与 t+dt 要分清。
  • Lax-Friedrichs 的人工粘性让它稳定但更耗散。
